# VibeMix — Catálogo de Playlist

Projeto acadêmico baseado no Trabalho 2 — Desenvolvimento Web.

## Estrutura
- `index.html` — catálogo principal
- `detalhes.html` — detalhes da música
- `playlist.html` — Minha Playlist/carrinho
- `css/style.css` — estilos
- `js/app.js` — array de objetos, filtros, ordenação e Local Storage
- `img/` — 12 capas SVG autorais estilizadas

## Recursos implementados
- 12 itens em array de objetos no JavaScript
- Cards Bootstrap
- Busca por nome/artista
- Filtro por gênero
- Filtro por duração
- Ordenação por nome, avaliação e duração
- Páginas HTML separadas
- Minha Playlist com Local Storage
- Alterar/remover quantidade
- Código especial `VIBEMIX10`
- Layout responsivo
- Tratamento de catálogo vazio
- Capas locais, sem depender de links externos para as imagens

## Publicação
Para GitHub Pages, envie a pasta para um repositório e ative Pages usando a branch principal e a pasta raiz.

Observação: as capas em SVG são artes visuais originais para o projeto e não reproduzem capas oficiais de álbuns.
